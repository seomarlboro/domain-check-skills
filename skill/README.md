# Claude Skill: Domain Check

Drop-in Skill for [Claude.ai](https://claude.ai) (Skills feature) to check domain availability.

## Install

1. Open Claude → Settings → Skills → **New skill**
2. Upload `SKILL.md` (or paste its contents)
3. Save. The skill auto-triggers when you ask about domains.

## Try it

> *"Is `nimbus-labs.com` available? If not, suggest alternatives across `.io`, `.ai`, `.co`."*

> *"What's the cheapest registrar for `.dev` over 3 years?"*
